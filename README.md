## Branch Management
- The `main` branch contains the stable code.
- Development should be done on a separate branch (e.g., `feature/new-feature`).
- Use `git checkout -b <branch-name>` to create a new branch.
- Use `git switch <branch-name>` to switch between branches.
- Use `git merge <branch-name>` to merge changes from one branch to another.
